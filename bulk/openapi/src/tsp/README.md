# Bulk API Defintion

This project defines the API for the protocol **Bulk API**.

Uses [TypeSpec](https://typespec.io/), a concise DSL to design high-quality Rest APIs.

From this spec, it is possible to generate:

- OpenAPI 3.x Specs
- Human documentation as HTML or other formats.
- Live Web for testing the API.
- Server-side skeleton for service implementation.
- Client-side proxies for service consumption.

## Build

```sh
npm i --force
npm run build
```
