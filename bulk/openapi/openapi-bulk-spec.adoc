= OpenAPI LionWeb Bulk Spec

This is a __proof of concept__ using the link:https://spec.openapis.org/oas/v3.2.0.html[**OpenAPI Specification**] describing the operations in the protocol for the **LionWeb Bulk Protocol**.
This specification formally describes the REST API, paths, operations and types to be used.

== Spec

Reference Spec: link:https://lionweb.io/specification/bulk/repo-access-api.html[Bulk Spec].
Definition of `LionWeb Chunk` adapted from: link:https://github.com/LionWeb-io/specification/blob/main/serialization/serialization.schema.json

**Artifacts:**

    1. The Bulk Spec as link:./bulk-openapi.yaml[YAML], generated, for machines. Located at `./bulk-openapi.yaml`.
    2. The Bulk Spec as link:./bulk-openapi.json[JSON], generated, for machines. Located at `./bulk-openapi.json`.
