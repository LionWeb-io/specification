[[evnt-ChildReplaced]]
===== Child replaced
<<existing-nodes, Existing node>> <<ChildReplaced.replacedChild>>, and all its <<ChildReplaced.replacedDescendants>>{fn-org370}, inside <<ChildReplaced.parent>>'s <<ChildReplaced.containment>> at <<ChildReplaced.index>> has been replaced with <<new-nodes, new>> or <<reused-nodes, reused>> node <<ChildReplaced.newChild>>.

<<ChildReplaced.replacedChild>>, and all its descendants, have been deleted.

See also <<splittableMessage>>.

.Technical name
`ChildReplaced`

[horizontal]
.Parameters
[[ChildReplaced.newChild, `newChild`]]newChild:: <<singleChunkType>>
Subtree that formed the new child.
The _anchor node_ MUST contain the <<ChildReplaced.parent>> as _parent_.{fn-org357}
All nodes in that subtree MUST be <<new-nodes>> or <<reused-nodes>>.{fn-org326}

[[ChildReplaced.replacedChild, `replacedChild`]]replacedChild:: <<nodeIdType>>
of the node that was replaced in <<ChildReplaced.containment>> of <<ChildReplaced.parent>> at <<ChildReplaced.index>>.

[[ChildReplaced.replacedDescendants, `replacedDescendants`]]replacedDescendants:: <<nodeIdType>>[]
List of all node ids that used to be descendants (including children and annotations) of <<ChildReplaced.replacedChild>>.
Does not include <<ChildReplaced.replacedChild>>.

[[ChildReplaced.parent, `parent`]]parent:: <<nodeIdType>>
of the node a child was replaced in.

[[ChildReplaced.containment, `containment`]]containment:: <<metaPointerType>>
<<{m3}.adoc#Containment, Containment>> <<ChildReplaced.replacedChild>> was replaced in <<ChildReplaced.parent>>.

[[ChildReplaced.index, `index`]]index:: <<indexType>>
where <<ChildReplaced.replacedChild>> was replaced in <<ChildReplaced.containment>> of <<ChildReplaced.parent>>.

[[ChildReplaced.split, `split`]]split?:: <<splitFlagType>>
Whether <<ChildReplaced.newChild>> is complete within this message.

[[ChildReplaced.originCommands]]originCommands:: <<commandSourceType>>[]
List of `(participationId, commandId)` pairs this event is based on.

[[ChildReplaced.sequenceNumber]]sequenceNumber:: <<eventSequenceType>>
Event sequence number of this event.

[[ChildReplaced.additionalInfos]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.
