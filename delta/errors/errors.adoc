[[errors]]
=== Errors
Commonly used errors, referred to by their _technical name_ as <<errorCodeType>>.

Additional infos of errors are optional.
A repository SHOULD provide them, if possible.
A client MUST NOT require them.

==== Error additional info types
Some types can only occur in additional infos of errors.

[[parameterType]]Parameter:: Technical name of the parameter an error refers to.

[[stringType]]string:: A string value.

[[serializedMetaPointerType]]Serialized MetaPointer:: string serialization of JSON representation of a <<{serialization}.adoc#meta-pointer, MetaPointer>>.
