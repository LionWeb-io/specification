[[errors-subscription]]
==== Subscription errors

[[err-mixedInformAboutAndSubscribeToChangingPartitions]]
===== Mixed Inform about / Subscribe to Changing Partitions
Client already <<qry-SubscribeToChangingPartitions, subscribed to changing partitions>>, and now requests to be <<qry-InformAboutChangingPartitions, informed about changing partitions>> -- or vice versa.

.Technical name
`mixedInformAboutAndSubscribeToChangingPartitions`

.Additional infos
[horizontal]
[[mixedInformAboutAndSubscribeToChangingPartitions.currentMode]]currentMode::
The technical name of the current subscription mode, i.e. either <<qry-InformAboutChangingPartitions>> or <<qry-SubscribeToChangingPartitions>>.
[[mixedInformAboutAndSubscribeToChangingPartitions.creation]]creation:: <<booleanType>>
Whether the participation is currently subscribed to newly created partitions.
[[mixedInformAboutAndSubscribeToChangingPartitions.deletion]]deletion:: <<booleanType>>
Whether the participation is currently subscribed to deleted partitions.
