[[cmd-ContinuedCommand]]
==== Continued Command
A <<continuedChunk>> for one of the following <<splittableMessage, splittable>> commands:{fn-org472}

* <<cmd-AddPartition>> <<AddPartition.newPartition>>
* <<cmd-AddChild>> <<AddChild.newChild>>
* <<cmd-ReplaceChild>> <<ReplaceChild.newChild>>
* <<cmd-AddAnnotation>> <<AddAnnotation.parent>>
* <<cmd-ReplaceAnnotation>> <<ReplaceAnnotation.newAnnotation>>

We identify the splittable command by its <<ContinuedCommand.commandId>>.

.Technical name
`ContinuedCommand`

[horizontal]
.Parameters
[[ContinuedCommand.chunk, `chunk`]]chunk:: <<deltaChunkType>>
The continued chunk.
The combination of all continued chunks MUST adhere to the same constraints as <<ContinuedCommand.commandId>>'s chunk.

[[ContinuedCommand.continuedChunkCompleted, `continuedChunkCompleted`]]continuedChunkCompleted:: <<continuedChunkCompletedFlagType>>
Whether this message completes <<ContinuedCommand.commandId>>.

[[ContinuedCommand.continuedChunkSequenceNumber, `continuedChunkSequenceNumber`]]continuedChunkSequenceNumber:: <<continuedChunkSequenceNumberType>>
Number of this message in the sequence of all continued commands relating to the same <<ContinuedCommand.commandId>>.

[[ContinuedCommand.commandId, `commandId`]]commandId:: <<commandIdType>>
Id of the related <<splittableMessage, splittable command>>

[[ContinuedCommand.additionalInfos, `additionalInfos`]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.

.Errors
* <<err-splitMessageAlreadyCompleted>>
* <<err-multipleContinuedChunksCompleted>>
* <<err-duplicateContinuedChunk>>
* <<err-unknownSplittableMessageInContinuedChunk>>
* <<err-invalidSplittableMessageInContinuedChunk>>
* <<err-interruptedContinuedChunk>>
* <<err-invalidParticipation>>
