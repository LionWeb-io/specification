[[qry-ContinuedQueryResponse]]
===== Continued query response
A <<continuedChunk>> for a <<splittableMessage, splittable>> response of one of the following queries:{fn-org472}

* <<qry-SubscribeToPartitionContents>> response <<SubscribeToPartitionContents.contents>>
* <<qry-ListPartitions>> response <<ListPartitions.partitions>>
* <<qry-ListAndSubscribePartitions>> response <<ListAndSubscribePartitions.partitions>>

We identify the splittable response by its <<ContinuedQueryResponse.queryId>>.

.Technical name
`ContinuedQueryResponse`

[horizontal]
.Response parameters
[[ContinuedQueryResponse.chunk, `chunk`]]chunk:: <<deltaChunkType>>
The continued chunk.
The combination of all continued chunks MUST adhere to the same constraints as <<ContinuedQueryResponse.queryId>>'s chunk.

[[ContinuedQueryResponse.continuedChunkCompleted, `continuedChunkCompleted`]]continuedChunkCompleted:: <<continuedChunkCompletedFlagType>>
Whether this message completes <<ContinuedQueryResponse.queryId>>.

[[ContinuedQueryResponse.continuedChunkSequenceNumber, `continuedChunkSequenceNumber`]]continuedChunkSequenceNumber:: <<continuedChunkSequenceNumberType>>
Number of this message in the sequence of all continued query responses relating to the same <<ContinuedQueryResponse.queryId>>.

[[ContinuedQueryResponse.queryId, `queryId`]]queryId:: <<queryIdType>>
Id of the related <<splittableMessage, splittable query>>.

[[ContinuedQueryResponse.additionalInfos, `additionalInfos`]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.

.Errors
* <<err-splitMessageAlreadyCompleted>>
* <<err-multipleContinuedChunksCompleted>>
* <<err-duplicateContinuedChunk>>
* <<err-unknownSplittableMessageInContinuedChunk>>
* <<err-invalidSplittableMessageInContinuedChunk>>
* <<err-interruptedContinuedChunk>>
* <<err-invalidParticipation>>
