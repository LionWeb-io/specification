[[cmd-DeleteAnnotation]]
===== Delete annotation
Delete <<existing-nodes, existing node>> <<DeleteAnnotation.deletedAnnotation>>{fn-org371} from <<DeleteAnnotation.parent>>'s annotations at <<DeleteAnnotation.index>>, and all its descendants (including annotation instances).
Does NOT change references to any of the deleted nodes.{fn-org285}

.Technical name
`DeleteAnnotation`

[horizontal]
.Parameters
[[DeleteAnnotation.parent, `parent`]]parent:: <<nodeIdType>>
of the node we want to delete an annotation from.

[[DeleteAnnotation.index, `index`]]index:: <<indexType>>
where we want to delete <<DeleteAnnotation.deletedAnnotation>> from in annotations of <<DeleteAnnotation.parent>>.

[[DeleteAnnotation.deletedAnnotation, `deletedAnnotation`]]deletedAnnotation:: <<nodeIdType>>
of the node we want to delete in annotations of <<DeleteAnnotation.parent>> at <<DeleteAnnotation.index>>.

[[DeleteAnnotation.commandId]]commandId:: <<commandIdType>>
Id of this command.

[[DeleteAnnotation.additionalInfos]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.

.Errors
* <<err-unknownNode>> for <<DeleteAnnotation.parent>>
* <<err-unknownNode>> for <<DeleteAnnotation.deletedAnnotation>>
* <<err-parentMismatch>> for <<DeleteAnnotation.parent>> and <<DeleteAnnotation.deletedAnnotation>>
* <<err-indexOutOfRange>> for <<DeleteAnnotation.index>> (is beyond (the number of annotations of <<DeleteAnnotation.parent>>) - 1)
* <<err-indexEntryMismatch>> for <<DeleteAnnotation.index>> and <<DeleteAnnotation.deletedAnnotation>>
* <<err-invalidParticipation>>
