[[evnt-AnnotationAdded]]
===== Annotation added
<<new-nodes, New node>> <<AnnotationAdded.newAnnotation>> has been added to <<AnnotationAdded.parent>>'s annotations at <<AnnotationAdded.index>>.

All other annotations inside <<AnnotationAdded.parent>>'s annotations with index >= <<AnnotationAdded.index>> have been moved to next higher index.

See also <<splittableMessage>>.

.Technical name
`AnnotationAdded`

[horizontal]
.Parameters
[[AnnotationAdded.parent, `parent`]]parent:: <<nodeIdType>>

[[AnnotationAdded.newAnnotation, `newAnnotation`]]newAnnotation:: <<singleChunkType>>
Subtree that formed the new annotation.
The _anchor node_ MUST contain the <<AnnotationAdded.parent>> as _parent_.{fn-org357}
All nodes in that subtree MUST be <<new-nodes>>.{fn-org326}

[[AnnotationAdded.index, `index`]]index:: <<indexType>>

[[AnnotationAdded.split, `split`]]split?:: <<splitFlagType>>
Whether <<AnnotationAdded.newAnnotation>> is complete within this message.

[[AnnotationAdded.originCommands]]originCommands:: <<commandSourceType>>[]
List of `(participationId, commandId)` pairs this event is based on.

[[AnnotationAdded.sequenceNumber]]sequenceNumber:: <<eventSequenceType>>
Event sequence number of this event.

[[AnnotationAdded.additionalInfos]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.
