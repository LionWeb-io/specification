[[cmd-AddChild]]
===== Add child
Add <<new-nodes, new node>> <<AddChild.newChild>> to <<AddChild.parent>> in <<AddChild.containment>> at <<AddChild.index>>.

See also <<splittableMessage>>.

.Technical name
`AddChild`

[horizontal]
.Parameters
[[AddChild.parent, `parent`]]parent:: <<targetNodeType>>
of the node we want to add a new child to.

[[AddChild.newChild, `newChild`]]newChild:: <<singleChunkType>>
Subtree to form the new child.
The _anchor node_ MUST contain the <<AddChild.parent>> as _parent_.{fn-org357}
All nodes in that subtree MUST be <<new-nodes>>.

[[AddChild.containment, `containment`]]containment:: <<metaPointerType>>
<<{m3}.adoc#Containment, Containment>> we want to add <<AddChild.newChild>> to in <<AddChild.parent>>.

[[AddChild.index, `index`]]index:: <<indexType>>
where we want to add <<AddChild.newChild>> at in <<AddChild.containment>> of <<AddChild.parent>>.
