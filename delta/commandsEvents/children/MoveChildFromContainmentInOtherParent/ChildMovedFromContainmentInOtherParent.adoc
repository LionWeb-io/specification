===== Child moved from containment in other parent
<<existing-nodes, Existing node>> <<ChildMovedFromContainmentInOtherParent.movedChild>> (previously inside <<ChildMovedFromContainmentInOtherParent.oldParent>>'s <<ChildMovedFromContainmentInOtherParent.oldContainment>> at <<ChildMovedFromContainmentInOtherParent.oldIndex>>) has been moved
inside <<ChildMovedFromContainmentInOtherParent.newParent>>'s <<ChildMovedFromContainmentInOtherParent.newContainment>> at <<ChildMovedFromContainmentInOtherParent.newIndex>>.

All other children inside <<ChildMovedFromContainmentInOtherParent.oldParent>>'s <<ChildMovedFromContainmentInOtherParent.oldContainment>> with index > <<ChildMovedFromContainmentInOtherParent.oldIndex>> have been moved to next lower index.

All other children inside <<ChildMovedFromContainmentInOtherParent.newParent>>'s <<ChildMovedFromContainmentInOtherParent.newContainment>> with index >= <<ChildMovedFromContainmentInOtherParent.newIndex>> have been moved to next higher index.
