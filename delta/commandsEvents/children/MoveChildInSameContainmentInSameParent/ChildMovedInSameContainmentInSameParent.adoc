===== Child moved in same containment in same parent
<<existing-nodes, Existing node>> <<ChildMovedInSameContainmentInSameParent.movedChild>>
that was initially at index <<ChildMovedInSameContainmentInSameParent.oldIndex>>
within the <<ChildMovedInSameContainmentInSameParent.containment>> inside <<ChildMovedInSameContainmentInSameParent.parent>>
was moved by <<ChildMovedInSameContainmentInSameParent.indexOffset>> positions
