[[evnt-ReferenceDeleted]]
===== Reference deleted
Existing reference with <<ReferenceDeleted.deletedReference>>/<<ReferenceDeleted.deletedResolveInfo>> has been deleted from <<ReferenceDeleted.parent>>'s <<ReferenceDeleted.reference>> at <<ReferenceDeleted.index>>.
All other entries inside <<ReferenceDeleted.parent>>'s <<ReferenceDeleted.reference>> with index > <<ReferenceDeleted.index>> have been moved to next lower index.

.Technical name
`ReferenceDeleted`

[horizontal]
.Parameters

of the node the reference has been deleted from.

[[ReferenceDeleted.reference, `reference`]]reference:: <<metaPointerType>>
<<{m3}.adoc#Reference, Reference>> that has been deleted from <<ReferenceDeleted.parent>>.

[[ReferenceDeleted.index, `index`]]index:: <<indexType>>
where <<ReferenceDeleted.deletedReference>> / <<ReferenceDeleted.deletedResolveInfo>> has been deleted at in <<ReferenceDeleted.reference>> of <<ReferenceDeleted.parent>>.
