===== ErrorEvent
Repository couldn't handle one or more command(s).{fn-org316}{fn-org405}

The repository MAY send an error event to only one participation.{fn-org379}

See also <<qry-ErrorResponse>>.

.Technical name
`ErrorEvent`

[horizontal]
.Parameters
[[Error.errorCode, `errorCode`]]errorCode:: <<errorCodeType>>
Code of the reported error.

[[Error.message, `message`]]message:: <<errorMessageType>>
Human-readable message of the error.

[[Error.originCommands]]originCommands:: <<commandSourceType>>[]
List of `(participationId, commandId)` pairs this event is based on.

[[Error.sequenceNumber]]sequenceNumber:: <<eventSequenceType>>
Event sequence number of this event.

[[Error.additionalInfos]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.
