[[evnt-ClassifierChanged]]
===== Classifier changed
Classifier of <<ClassifierChanged.node>> has been changed from <<ClassifierChanged.oldClassifier>> to <<ClassifierChanged.newClassifier>>.

.Technical name
`ClassifierChanged`

[horizontal]
.Parameters
[[ClassifierChanged.node, `node`]]node:: <<nodeIdType>>
of the node whose classifier has been changed.

[[ClassifierChanged.newClassifier, `newClassifier`]]newClassifier:: <<metaPointerType>>
New <<{m3}.adoc#Classifier, Classifier>> of <<ClassifierChanged.node>>.

[[ClassifierChanged.oldClassifier, `oldClassifier`]]oldClassifier:: <<metaPointerType>>
Old <<{m3}.adoc#Classifier, Classifier>> of <<ClassifierChanged.node>>.

[[ClassifierChanged.originCommands]]originCommands:: <<commandSourceType>>[]
List of `(participationId, commandId)` pairs this event is based on.

[[ClassifierChanged.sequenceNumber]]sequenceNumber:: <<eventSequenceType>>
Event sequence number of this event.

[[ClassifierChanged.additionalInfos]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.
