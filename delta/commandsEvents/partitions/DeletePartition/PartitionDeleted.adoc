[[evnt-PartitionDeleted]]
===== Partition deleted
Partition <<PartitionDeleted.deletedPartition>>, and all its <<PartitionDeleted.deletedDescendants>>{fn-org370}, have been deleted from the repository.

This client is now unsubscribed from any changes to <<PartitionDeleted.deletedPartition>> or any of its descendants.

.Technical name
`PartitionDeleted`

[horizontal]
.Parameters
[[PartitionDeleted.deletedPartition, `deletedPartition`]]deletedPartition:: <<nodeIdType>>
of the partition that has been deleted.

[[PartitionDeleted.deletedDescendants, `deletedDescendants`]]deletedDescendants:: <<nodeIdType>>[]
List of all node ids that used to be descendants (including children and annotations) of <<PartitionDeleted.deletedDescendants>>.
Does not include <<PartitionDeleted.deletedDescendants>>.
