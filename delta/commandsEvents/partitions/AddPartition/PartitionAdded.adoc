[[evnt-PartitionAdded]]
===== Partition added
<<new-nodes, New>> partition <<PartitionAdded.newPartition>> has been added to the repository.

See also <<splittableMessage>>.

.Technical name
`PartitionAdded`

[horizontal]
.Parameters
[[PartitionAdded.newPartition, `newPartition`]]newPartition:: <<singleChunkType>> (if subscribed via <<qry-ListAndSubscribePartitions>> or <<qry-SubscribeToChangingPartitions>>) or +
<<shallowChunkType>> (if subscribed via <<qry-InformAboutChangingPartitions>>) up to <<InformAboutChangingPartitions.depthLimit>>.
+
NOTE: This parameter differs from the <<AddPartition.newPartition, corresponding command parameter>>:
The command's parameter always contains a whole subtree, whereas the event's parameter may contain only the top of the subtree.{fn-org425}

[[PartitionAdded.split, `split`]]split?:: <<splitFlagType>>
Whether <<PartitionAdded.newPartition>> is complete within this message.

[[PartitionAdded.originCommands]]originCommands:: <<commandSourceType>>[]
List of `(participationId, commandId)` pairs this event is based on.

[[PartitionAdded.sequenceNumber]]sequenceNumber:: <<eventSequenceType>>
Event sequence number of this event.

[[PartitionAdded.additionalInfos]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.
