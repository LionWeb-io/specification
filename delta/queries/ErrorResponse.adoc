[[qry-ErrorResponse]]
===== Error response
Any query might return with error parameters instead of its declared response parameters.{fn-org405}

See also <<evnt-ErrorEvent>>.

.Technical name
`ErrorResponse`

[horizontal]
.Response parameters
[[ErrorResponse.errorCode, `errorCode`]]errorCode:: <<errorCodeType>>
Code of the reported error.

[[ErrorResponse.message, `message`]]message:: <<errorMessageType>>
Human-readable message of the error.

[[ErrorResponse.queryId, `queryId`]]queryId:: <<queryIdType>>
Id of the related query.

[[ErrorResponse.additionalInfos, `additionalInfos`]]additionalInfos:: <<additionalInfosType>>
Optionally empty list of <<additionalInfo>>s.
